## 桌面界面与文件

已启动发布目录的真实 EXE，核对连接、EQ 数据展示、备份与诊断页面。界面成功连接 1.6.0 耳机，电量定时读取持续返回。已经确认连接备份真实落盘。没有逐个点击所有设置按钮；写入与恢复主要通过同一控制器的硬件测试程序验证。

## 开发中发现并修正的问题

1. 一次 43 字节整段 EQ TX 被固件静默截断，读回发现 EQ 尾部改变。改为五个 15 字节单段 TX，恢复原始备份并逐字节核对；最终测试再次验证变更与恢复。发布版硬限制 TX ≤20 字节。
2. 提示音 GET/SET 百分比量化不对称，直接回写 56 会成为 50。已用 SET 57 恢复读回 56，按离散档位编码；50、56、62 附近的实验通过。
3. Windows 音频设备集合接口 GUID 初稿错误，已用本机 Windows SDK 头文件修正，两个真实音频端点的音量变更和恢复通过。

原始日志与所有本机设备备份仍保留在开发目录，不进入发布包。测试记录是有限样本验证，不是全部固件兼容性、听感、低延迟或长时间稳定性证明。自动恢复在断连时无法保证完成；本轮没有故意制造写入中断来测试该分支。
